# 合并书目下的预约先后与副本兑现

Python 3.11 + 标准库 SQLite，无第三方依赖。全部数据合成，材料输入在
`materials/765/input.json`。

## 运行

```bash
python3.11 demo.py                      # 端到端演示，内置断言，退出码 0 即全部兑现
python3.11 royalty_demo.py              # 权利室+版税结算端到端演示（含题目三组数字场景）
python3.11 -m unittest tests -v         # 32 个测试（含 500 副本/1000 票据规模用例）
python3.11 -m unittest royalty_tests -v # 20 个权利室/结算测试（含 12 版/10 池上限）
```

## 两个独立子系统

### 目录（`library/catalog.py`）

- 每个修订是**不可变全量快照**：稳定书目 ID、单向别名边、各副本的原始书目 ID、
  取件馆、装帧。副本 `copy_id` 跨修订稳定。
- 边终点必须存在；每书目至多一条出边；允许多对一与多跳；**含环（含自环）整批拒绝**，
  库内不留半截数据。
- 规范书目在查询时沿边多跳现算（`canonical_map`）；目录里没有读者、票据或顺序。
- 错误别名只能由后续修订“不再声明该边”拆除；任一旧修订仍可完整查询，
  成员原 ID 与每副本原始身份不被揉掉。

### 台账（`library/ledger.py`）

- 等待票据永久保留**原书目 ID**、到达序号、允许馆/装帧集合；同序号按票据 ID 固定排序。
- 挑选只在 `waiting` 票据中进行：票据原书目经**当前头修订**解析到的规范作品与副本一致、
  馆/装帧在允许集合内，取 `(arrival_seq, ticket_id)` 最早者；运营方无法跳过较早合格票。
- 保留建立即锁定当时票据、读者、馆、副本与修订；之后目录更正不改派已保留副本。
  部分唯一索引保证一票据/一副本同时至多一条未释放保留。
- 两步式 `prepare`/`commit`：准备后若头修订变化或等待版本变化（新票/提交/释放），
  提交旧准备一律拒绝；也提供一步式 `reserve`。
- 取件只兑现保留给定的票据/读者/副本，错误读者拒绝且不消耗保留；
  过期/取消先释放（票据带原序号回队），再按当前目录重新挑人，旧回执保留。
- 操作 ID + 请求指纹：同文重放原样返回，异文抛 `IdempotencyConflict` 且不写库；
  业务拒绝落 `rejected` 回执，失败不产生部分占用。

| 操作 | 结果 |
| --- | --- |
| P1（v1 预览 C1） | 命中 TA；TB 要 WB/精装，v1 下与 C1 不同作品 |
| 切 v2（WB→WA 合并） | P1 随即失效 |

## 权利室（`library/rights.py`）与版税结算（`library/royalties.py`）

### 权利室：印次权段 → 真实借次

- 实际取走的是**某一册的某一印次**，不是当前规范作品名。`rights_impressions`
  为副本登记印次，`rights_segments` 留当时适用的内容清单，每段含具名作者、
  合同版号、权段号；同一合同版可跨多册出现。
- 借次只认台账 `reservations` 中 `fulfilled` 的成功取件：失败、过期、未取件的
  保留认领一律 `hold_not_fulfilled` 拒绝，同操作重放原样返回，均不生借次。
- 认领即逐段复制清单快照（`claim_segments`），后续目录合并/拆别名不回写真实借出的版。
- 去重口径落在部分唯一索引上：**同读者、同业务日、同作者、同合同版、同权段只计一次**；
  合订本不同权段、不同读者分别计。`recognized_loan_claims` 保留一条已计借次对应的
  全部真实取件（含被去重的重复件），`audit_loan` 可独立复核。
- `library_reports` 只存馆报数字，没有真实取件支撑，结算代码路径从不读取。

### 结算：单开 / 共池 / 最优枚举 / 幂等过账

- **单开**：各版按当期真实借次选费率，低于门槛普通费、达门槛则全期每次改新费；
  本版期初预付只抵本版应付，多余留到下期，不跨版挪借。
- **共池**：协议列必须整组参加的版号、池门槛与两档单价、抵款先后与办理费；
  入池版真实借次合计后共用池费率，按条款顺序用组内各版余额抵池总应付，
  余款另付作者；办理费另付且不可用预付抵。选中的池彼此不得共用任何一版；
  无借次的版可带自己的预付入获准池，未入池无豁免的版只能单开。
- 每期 ≤12 版、≤10 池：枚举全部互不重叠的池子集（≤1024 种）取新增现金最低的
  确定性方案；`check_grouping` 核验外部指定分组，`evaluate_protecting`
  在现金预算内强制某版预付一分不扣供下期。
- 过账每期一次且幂等：过账前用库内真实余额/借次复算方案，异方案二次过账拒绝；
  重读回执或同文重放不再吃余额。次期开账只沿用上期 `prepay_after` 真实所余，
  可再显式注入新预付。清算单分开列作者补款、办理费、各版预付实扣与剩余。

### 题目数字场景的兑现（`royalty_demo.py`，费率 <3 次每次 4、≥3 次每次 6）

| 场景 | 单开新增现金 | 并池新增现金 | 最优 |
| --- | --- | --- | --- |
| ① A=1、B=1，预付 A=8，池费 1 | 4（B 补 4，A 抵 4 余 4） | 1（池应付 8 全抵，A 余 0，仅费 1） | 并池 **1** |
| ② 另一读者再借含 B 权段一册（B 添 1，池合计 3） | 8（B 两次普通费） | 11（3×6=18 抵 8 补 10，加费 1） | 单开 **8** |
| ③ 恢复原借次，仅池费改 6 | 4 | 6（费 6） | 单开 **4** |

## 代码地图

```
library/db.py        SQLite schema、显式事务、操作指纹、回执与版本计数器
library/catalog.py   修订快照、边校验/环检测、多跳规范解析、拆别名、目录查询
library/ledger.py    票据、prepare/commit、reserve、pickup、release、公开查询
library/rights.py    印次/权段登记、取件认领、去重认列借次、借次复核、馆报留痕
library/royalties.py 期间配置、单开/共池枚举、外部分组核验、预算保版、幂等过账、结转
library/system.py    门面与重开（LibrarySystem.reopen）
demo.py              材料严格重放 + 拆别名/环拒绝/过期重选/幂等/重开场景
royalty_demo.py      真实取件→认列→三组数字结算→分组核验→保版→过账→次期结转
tests.py             目录/台账单元测试与规模验证
royalty_tests.py     权利室/结算单元测试与 12 版 10 池上限验证
```
