# 同一刀两个不同偏高刀口擦过同一格

标高 `[1,1,1]`、闭口 C=2，蓄水 `[1,1,1]`，毛坯 M=2，目标厚度 `[1,1,1]`。

刀 Z 在**同一相对偏移 (0,0)** 上有两个刀口：偏高 0 与偏高 2，另有一个
(0,1) 偏高 0 的刀口。行程 Z-0 刀柄在第 0 格、整趟高度固定：

- 第 0 格同时被偏高 0 与偏高 2 的刀口擦到。刀柄高度 h 时两刀口分别把该格
  留到厚度 h 与 h+2，取**最低**者 h；
- 若只信偏高 2 的刀口，会得到 h = 目标 − 2 = −1，夹到 0，此时偏高 0 的刀口
  把第 0 格切到厚度 0，低于目标 1——过切；
- 正确的最低安全刀柄高度是 max(1−0, 1−2, 1−0) = **1**，第 0、1 格都恰切到 1。

点刀 P3 补第 2 格。整单 Z-0 + P3，费 3，确认时揭 S-Z。

这是对“同一格先后被同一刀的两个不同偏高刀口擦过，应取最低切到厚度、
不得刨薄过头”的直接核验。
